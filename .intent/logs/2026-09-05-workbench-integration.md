# Workbench integration verification

The private Web profile reproduces the installed package set and loads the sidebar, generic viewer, lazy CodeMirror module and file manager as separate contributions. Browser exercise exposed a Cordis receiver problem with native private methods; the Remote now uses proxy-compatible TypeScript-private methods, with a real Cordis receiver regression. Directory Chat links route to the tree, optional native-open detection can fail without blocking the provider, and source breadcrumbs launch the selector through the sidebar API.

Tree row actions use compact labelled icons and scoped styling; long names retain the row width, and cyclic symbolic-link expansion is disabled. Duplicate wire interface declarations were removed. Linux moves use configurable GNU mv with no-clobber and no-copy options; independent manager calls cannot replace the winning destination. Trash confirmation remains path-based rather than inode-pinned and is explicitly documented as such.

Verification before live installation: 20 focused tests pass, including Host receiver dispatch, source/watch routing, independent move contenders, staged guarded saves, recoverable fixture trash and UTF-8/EOL behavior. Host/Typert/Client build passes against the candidate alpha.2 Host. Live activation evidence will be recorded separately.
